# js-glassmorphism-ui 🧊

A modern Glassmorphism style UI built using HTML, CSS and JavaScript.

## ✨ Features
- Glassmorphism design
- Frosted glass effect
- Modern gradient background
- Clean UI

## 🛠 Technologies
- HTML
- CSS (backdrop-filter)
- JavaScript

## 🚀 Usage
Open `index.html` to view glassmorphism UI.
